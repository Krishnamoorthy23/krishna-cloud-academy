# Krishna Cloud Academy

A professional static Cloud / DevOps / AI training website designed for Vercel deployment.

## Included
- Responsive navigation and mobile menu
- Courses: AWS, Azure, GCP, DevOps, Kubernetes, AI
- Hands-on labs and project showcase
- Career roadmap
- Trainer profile and learner feedback
- FAQ and enquiry form
- No external dependencies or API keys

## Run locally
Open the folder with VS Code and use Live Server, or run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy to Vercel
Push this folder to GitHub and import the repository into Vercel. This is a static site, so no build command is required.

Before production, replace the demo contact email and connect the form to a real form/email backend.
